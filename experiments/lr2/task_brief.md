# Task Brief: експеримент ЛР №2 (реалізація без AI та з AI)

Це заморожене єдине формулювання задачі для обох незалежних реалізацій. Текст не змінюється між етапами.

## Функція для реалізації

Реалізуйте чисту Python-функцію з точною назвою та сигнатурою:

`matches_item_filter(item, *, category_id=None, is_purchased=None) -> bool`

- Ручний варіант (без AI): `experiments/lr2/manual_impl.py`
- AI-варіант (в окремому чистому сеансі): `experiments/lr2/ai_impl.py`

## Вимоги (за `docs/requirements.md`: FR-07, BR-04, D-05, AC-07-01–AC-07-03)

1. **Вхідна позиція (`item`):**
   - `item` є словником коректної товарної позиції `ShoppingItem` з полями контракту (`id`, `list_id`, `name`, `quantity`, `unit`, `category_id`, `is_purchased`, `created_at`).
   - Вхідний `item` вважається коректним за контрактом; додаткову валідацію всіх полів позиції додавати не потрібно.
2. **Параметр `category_id` (keyword-only, типово `None`):**
   - Допустимі значення: `None` (фільтр не застосовується) або точний тип `int` у діапазоні `1..10` включно.
   - Некоректне значення або некоректний тип (зокрема `bool` `True`/`False`, числа поза `1..10`, рядки, `float`, інші типи) повинні викликати `ValueError`.
3. **Параметр `is_purchased` (keyword-only, типово `None`):**
   - Допустимі значення: `None` (фільтр не застосовується) або точний тип `bool` (`True` або `False`).
   - Некоректне значення або некоректний тип (зокрема цілі `0`/`1`, рядки `"true"`/`"false"`/`"True"`, `float`, інші типи) повинні викликати `ValueError`.
4. **Логіка фільтрації:**
   - Якщо обидва фільтри відсутні (`category_id is None` і `is_purchased is None`), функція повертає `True`.
   - Якщо передано один фільтр, функція повертає `True` або `False` залежно від відповідності позиції цьому фільтру.
   - Якщо передано обидва фільтри, функція повертає `True` лише за одночасної відповідності обом умовам (логічне `AND`).
   - Не допускайте неявного змішування `bool` та `int`.
   - Результат завжди має точний тип `bool`.
5. **Чистота та ізоляція:**
   - Функція не змінює вхідний словник `item`.
   - Функція не використовує FastAPI, SQLite, мережу, файлову систему або сторонні залежності.

## Правила незалежності експерименту

- Обидві реалізації створюються виключно на основі цього Task Brief.
- Ручний варіант виконується першим, повністю без AI-чату й без AI-автодоповнення.
- AI-варіант виконується другим у новому чистому сеансі без доступу до `experiments/lr2/manual_impl.py`, `tests/test_experiment_lr2.py` та коду `app/`.
- Для обох варіантів окремо фіксуються результати першого прогону тестів, кількість ітерацій виправлень, виявлені дефекти, фактичний час виконання та фінальний результат.
