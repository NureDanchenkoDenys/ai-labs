# Інтелектуальна система керування списком покупок

Лабораторна робота 1 з дисципліни «Штучний інтелект у програмній інженерії».

**Команда:** Данченко Денис; Пархоменко Олександр.
**AI-інструмент команди:** ChatGPT, GPT 6.1 Sol, режим «Дуже високе» — за даними, наданими Данченком Денисом.
**Версія специфікації:** lab01-spec. **Дата:** 19.11.2026.

## Про проєкт

Система допомагає створювати списки покупок, додавати товари з кількістю, одиницею та категорією, редагувати й видаляти позиції, позначати придбання, застосовувати фільтри та переглядати загальну й категорійну статистику. У ЛР4 готова NLP-модель рекомендуватиме категорію за змістом назви товару. Остаточне рішення завжди приймає користувач.

Рекомендований стек збережено: **Python, FastAPI, SQLite, pytest**. Поточний обсяг — FR-01–FR-08; FR-09 специфікована для ЛР4. ЛР1 містить вимоги та проєктування, реалізація застосунку належить до наступних робіт.
