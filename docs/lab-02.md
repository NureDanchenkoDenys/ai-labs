# Звіт про виконання лабораторної роботи 2

## Перевірка Skill v0

Проведено чотири перевірки Skill `tracker-slice` у чотирьох окремих сеансах.

| № | Запит | Очікувана активація | Спостережуваний результат | Висновок |
| --- | --- | --- | --- | --- |
| 1 | План реалізації `POST /lists` | Так | Агент прочитав `SKILL.md` і `references/slices.md`, визначив `FR-01` / `US-01` і підготував план без змін файлів. | Активація спостерігалася, результат відповідає очікуванню. |
| 2 | План тестів `GET /lists/{list_id}/statistics` | Так | Агент прочитав `SKILL.md` і `references/slices.md`, визначив `FR-08` / `US-08` і підготував план без змін файлів. | Активація спостерігалася, результат відповідає очікуванню. |
| 3 | Пояснення різниці HTTP 404 і 422 | Ні | Агент надав текстову відповідь, дій читання Skill у журналі не спостерігалося. | Видимих ознак активації у журналі не зафіксовано. |
| 4 | Пояснення створення Python `venv` у Windows | Ні | Агент надав текстову відповідь, дій читання Skill у журналі не спостерігалося. | Видимих ознак активації у журналі не зафіксовано. |

### Висновок

У позитивних перевірках (№ 1 і № 2) агент активував Skill і підготував плани без змін файлів, але читав більше документів, ніж потрібно для одного зрізу; зменшення обсягу зайвого читання є потенційним напрямом удосконалення для Skill v1. У негативних перевірках (№ 3 і № 4) дій читання Skill у журналі не спостерігалося, однак відсутність видимих дій сама по собі не є гарантованим доказом того, що Skill не використовувався.
